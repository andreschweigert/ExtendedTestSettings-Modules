# ExamSymbols

Externes Modul für das ILIAS-Plugin **ExtendedTestSettings**.

Stellt während einer Prüfung eine klickbare Sonderzeichen-Palette zur Verfügung (Shortcut: `Alt + S`). Unterstützt verschiedene Fachbereichs-Templates (Mathematik, Griechisch, Chemie, Physik, Spanisch, Französisch, Italienisch, Deutsch) und funktioniert mit Rich-Text-Editoren (TinyMCE, CKEditor).
