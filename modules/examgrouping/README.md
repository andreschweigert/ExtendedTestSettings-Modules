# ExamGrouping

Externes Modul für das ILIAS-Plugin **ExtendedTestSettings**.

Erlaubt es, die Fragen eines Tests zu benannten Gruppen zusammenzufassen und die Gesamtpunktzahl je Gruppe aus den Testergebnissen auszuwerten.
