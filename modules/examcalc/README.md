# ExamCalc

Externes Modul für das ILIAS-Plugin **ExtendedTestSettings**.

Stellt während einer Prüfung einen Taschenrechner als schwebenden Button (Shortcut: `Alt + R`) zur Verfügung. Zwei Modi: einfacher Taschenrechner (Grundrechenarten) und wissenschaftlicher Taschenrechner (sin, cos, tan, √ — Beta).
